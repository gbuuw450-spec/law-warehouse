## 화면에서 확인한 것

- 로그인: 틀린 비밀번호는 "비밀번호가 다릅니다 (남은 횟수 N회)" 표시, 맞으면 검색 화면으로 이동, 새로 열어도 로그인 유지
- 주민등록번호 형태 입력: "주민등록번호로 보이는 숫자가 있습니다" 경고가 뜨고 검색되지 않음
- 토글: `법령` / `선결정례 등` 전환과 건수 표시
- 본문보기: 결정례는 전문(약 2만 자)이 펼쳐짐. 본문이 없는 판결은 "원문 페이지에서 보기" 링크가 나옴
- 더보기: 5건 → 10건으로 늘어남
- 휴대폰 크기(가로 375px): 가로 스크롤 없음

## 확인하지 못한 것

- 5회 틀렸을 때의 10분 잠금 (화면에서 끝까지 시험하지 않음)
- 조회 실패와 60초 초과 때의 "다시 시도" 화면 (일부러 실패를 일으켜 보지 않음)
- `더보기`를 끝까지 눌러 법령 10개, 사례 20건에서 멈추는지

## 알려진 한계

1. **국세법령정보시스템 출처 판결은 결과에서 제외된다.** 법제처 API가 이 출처의 본문을 주지 않아 요약과 본문보기를 할 수 없기 때문이다. 조세 판결의 대부분이 이 출처라서, 결과는 조세심판원 결정례가 중심이다. (위 "테스트 사례별 결과" 표는 이 변경 전에 측정한 것이라 해당 출처 판결이 들어 있다. 변경 후 1번과 4번 사례를 다시 돌려 20.6초, 19.6초에 결과가 나오고 해당 출처 판결이 없는 것을 확인했다.)
2. **부칙은 "입력 시점에 시행 중이던 조문을 고르는 것"까지만 반영했다.** 부칙의 경과규정·적용례 문구를 따로 찾아 보여 주지는 않는다.
3. **로그인 잠금은 브라우저 단위다.** 다른 브라우저로 바꾸면 다시 시도할 수 있다.
4. **법령 조문은 AI가 제안한 후보를 법제처 API로 확인하는 방식이다.** AI가 떠올리지 못한 조문은 목록에 나오지 않는다.
