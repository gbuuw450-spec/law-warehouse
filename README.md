# 법률창고

세무사가 사건의 **사실관계**를 적으면 관련 **법령**, **조세심판원 선결정례**, **법원 판결**을 찾아 요약해 주는 검색 앱입니다.

키워드가 아니라 사실관계로 찾고, 찾은 사례마다 "이 사례는 ~한 사례로서 조세심판원은 ~게 결정하였다" 형식의 요약을 먼저 보여 줍니다. 법령 조문과 사건번호는 법제처 Open API에서 실제로 조회된 것만 표시합니다.

## 주요 기능

- **사실관계로 관련 법령 찾기**: 쟁점을 2문장 이내로 정리하고, 관련 조문을 최대 10개까지 보여 줍니다. 사실관계에 연도가 명확하면 그 시점에 시행 중이던 조문을 찾습니다.
- **선결정례·판례 찾기와 요약**: 사건번호와 결과(인용, 기각 등)를 먼저 보여 주고, 3문장 이내의 요약과 `본문보기`를 제공합니다. 최대 20건까지 5건씩 볼 수 있습니다.
- **개인정보 보호**: 주민등록번호나 사업자등록번호 형태의 숫자가 있으면 전송 전에 경고하고 검색을 멈춥니다. 입력한 사실관계와 결과는 서버에 저장하지 않습니다.
- **간단한 로그인**: 비밀번호 한 개로 들어갑니다.

## 화면 구성

- 위쪽: `법령` / `선결정례 등` 전환 버튼
- 가운데: 사실관계를 길게 적을 수 있는 검색창
- 아래쪽: 쟁점 정리와 결과 목록

## 동작 방식

1. AI가 사실관계에서 쟁점, 검색어, 법령 후보를 뽑습니다.
2. 법제처 Open API에서 법령 조문, 조세심판원 결정례, 법원 판결을 조회합니다.
3. AI가 조회된 사례만 관련성 순으로 줄 세웁니다.
4. AI가 조회된 본문을 근거로 요약합니다.

검색은 고른 토글의 범위만 합니다. `법령` 토글에서 검색하면 법령만 찾고, `선결정례 등` 토글로 옮기면 그때 사례를 찾습니다.

AI는 검색어를 만들고, 줄을 세우고, 요약만 합니다. 사건번호, 조문, 본문은 항상 법제처 API에서 받은 값을 씁니다.

## 기술 스택

- Next.js (화면과 서버 쪽 코드를 한 프로젝트에서 처리)
- OpenAI API (쟁점 정리, 관련성 정렬, 요약)
- 법제처 Open API (법령, 판례, 조세심판원 결정례)
- Vercel (배포)

## 내 컴퓨터에서 실행하기

1. 프로젝트 폴더에 `.env` 파일을 만들고 아래 네 값을 넣습니다. 이 파일은 `.gitignore`에 등록되어 있어 저장소에 올라가지 않습니다.

   ```
   OPENAI_API_KEY=
   OPENAI_MODEL=
   LAW_API_KEY=
   APP_PASSWORD=
   ```

2. 필요한 부품을 설치하고 실행합니다.

   ```
   npm install
   npm run dev
   ```

3. 브라우저에서 `http://localhost:3000`을 엽니다.

## 확인용 명령어

| 명령어 | 하는 일 |
|---|---|
| `npm run check:law` | 법제처 API 연결 확인 |
| `npm run check:openai` | OpenAI 연결 확인 |
| `npm run test:cases` | 테스트 사례 6건 검색 (앱이 실행 중이어야 함) |
| `npm run build` | 빌드해서 오류 확인 |

## 알려진 한계

- 국세법령정보시스템 출처의 법원 판결은 법제처 API가 본문을 제공하지 않아 결과에서 제외합니다. 그래서 결과는 조세심판원 결정례가 중심입니다.
- 부칙의 경과규정 문구는 따로 보여 주지 않습니다.
- 요약은 AI가 만든 참고 자료입니다. 실제 업무에는 반드시 원문을 확인하세요.
